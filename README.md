# Проверка характеристик числа

## Назначение
Консольное приложение на Python для анализа целого числа, введённого пользователем.

## Задачи
- Определить: положительное, отрицательное или ноль
- Определить: чётное или нечётное
- Проверить делимость на 3
- Проверить делимость на 5
- Проверить, является ли число простым
- Посчитать количество цифр
- Проверить, является ли число полным квадратом
- Обработать случай, когда введено не число

## Новый функционал (Практическая работа №2)
- Добавлена возможность анализировать несколько чисел подряд в одном сеансе.
- Добавлена проверка, является ли число квадратом целого числа.
- Добавлена защита от некорректного ответа на вопрос о продолжении работы (принимается только "да" или "нет").

## Запуск
Для запуска программы выполните команду в терминале:
python 2практика.py

## Использование
1. Запустите программу.
2. Введите целое число.
3. Получите характеристики числа.
4. На вопрос "Проверить ещё одно число?" введите "да" или "нет".
